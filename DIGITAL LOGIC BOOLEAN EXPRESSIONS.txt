                                                  DIGITAL LOGIC BOOLEAN EXPRESSIONS
                                     Notation:  ⊕ = XOR  |  ⊙ = XNOR  |  Ā = Complemented (NOT A)
===================================================================================================================================

1. HALF ADDER (Inputs: A, B)
-----------------------------------------------------------------------------------------------------------------------------------
   Sum   = A ⊕ B
   Cout  = A · B


2. FULL ADDER (Inputs: A, B, Cin)
-----------------------------------------------------------------------------------------------------------------------------------
   Sum   = A ⊕ B ⊕ Cin
   Cout  = (A · B) + (Cin · (A ⊕ B))
         = (A · B) + (B · Cin) + (A · Cin)


3. HALF SUBTRACTOR (Inputs: A, B)
-----------------------------------------------------------------------------------------------------------------------------------
   Diff  = A ⊕ B
   Bout  = Ā · B


4. FULL SUBTRACTOR (Inputs: A, B, Bin)
-----------------------------------------------------------------------------------------------------------------------------------
   Diff  = A ⊕ B ⊕ Bin
   Bout  = (Ā · B) + (Bin · (A ⊙ B)) 
   
         = Ā·B + ~(A ⊕ B)·Bin
		 
         = (Ā · B) + (Ā · Bin) + (B · Bin)


5. 1-BIT COMPARATOR (Inputs: A, B)
-----------------------------------------------------------------------------------------------------------------------------------
   A_gt_B (A > B)  = A · B̅
   A_lt_B (A < B)  = Ā · B
   A_eq_B (A == B) = A ⊙ B
                   = (A · B) + (Ā · B̅)

===================================================================================================================================
                                      XOR GATE CONTROL BEHAVIOR (PROGRAMMABLE INVERTER / BUFFER)
===================================================================================================================================

1. XOR GATE AS A BUFFER / PASS-THROUGH (Control Input = 0)
-----------------------------------------------------------------------------------------------------------------------------------
   - Boolean Expression : Y = A ⊕ Control
   - When Control = 0   : Y = A ⊕ 0 = A
   - Hardware Behavior  : The input signal 'A' passes through to output 'Y' unchanged.
                          The XOR gate functions as a non-inverting BUFFER.


2. XOR GATE AS AN INVERTER (Control Input = 1)
-----------------------------------------------------------------------------------------------------------------------------------
   - Boolean Expression : Y = A ⊕ Control
   - When Control = 1   : Y = A ⊕ 1 = Ā  (~A)
   - Hardware Behavior  : The input signal 'A' is complemented (inverted) at output 'Y'.
                          The XOR gate functions as an INVERTER (NOT gate).


3. HARDWARE APPLICATION (CONTROLLED INVERTER)
-----------------------------------------------------------------------------------------------------------------------------------
   - Because of these dual modes, the XOR gate is known as a CONTROLLED INVERTER (or Programmable Inverter).
   - Primary Application: Used in Adder/Subtractor circuits to conditionally complement the subtrahend input B 
     when Sub = 1 to perform 2's complement subtraction.

===================================================================================================================================

===================================================================================================================================
                                         OR GATE CONTROL BEHAVIOR (BUFFER vs. FORCE-HIGH)
===================================================================================================================================

1. OR GATE AS A BUFFER / PASS-THROUGH (Control Input = 0)
-----------------------------------------------------------------------------------------------------------------------------------
   - Boolean Expression : Y = A + Control
   - When Control = 0   : Y = A + 0 = A
   - Hardware Behavior  : The input signal 'A' passes through to output 'Y' unchanged. 
                          The OR gate functions as a non-inverting BUFFER.


2. OR GATE CONTROL AT HIGH (Control Input = 1)
-----------------------------------------------------------------------------------------------------------------------------------
   - When Control = 1   : Y = A + 1 = 1
   - Hardware Behavior  : Output 'Y' is forced HIGH (1) regardless of input 'A'. 
                          It acts as a FORCE-HIGH / SET control line.


3. NOTE ON INVERSION
-----------------------------------------------------------------------------------------------------------------------------------
   - A standard OR gate CANNOT act as an inverter on its own (Control = 0 gives A; Control = 1 gives 1).
   - To achieve signal inversion with single-input control, use:
       a) NOR Gate with Control = 0 : Y = ~(A + 0) = Ā  (INVERTER)
       b) XOR Gate with Control = 1 : Y = A ⊕ 1   = Ā  (INVERTER)

1. 3-BIT BINARY UP COUNTER (State: Q2 Q1 Q0 | LSB: Q0, MSB: Q2)
-----------------------------------------------------------------------------------------------------------------------------------
   [D FLIP-FLOP EQUATIONS] (D_i = Next State Q_i+)
   D0 = Q̄0
   D1 = Q1 ⊕ Q0
   D2 = Q2 ⊕ (Q1 · Q0)

   [T FLIP-FLOP EQUATIONS] (T_i = Toggle Condition)
   T0 = 1
   T1 = Q0
   T2 = Q1 · Q0
   
   - Down Counter : T0 = 1; 
                    T1 = ~Q0;   
					T2 = ~Q1 & ~Q0;


2. 4-BIT BINARY UP COUNTER (State: Q3 Q2 Q1 Q0 | LSB: Q0, MSB: Q3)
-----------------------------------------------------------------------------------------------------------------------------------
   [D FLIP-FLOP EQUATIONS] (D_i = Next State Q_i+)
   D0 = Q̄0
   D1 = Q1 ⊕ Q0
   D2 = Q2 ⊕ (Q1 · Q0)
   D3 = Q3 ⊕ (Q2 · Q1 · Q0)
   
  - D0 = ~Q0
  - D1 = Q1 ⊙ Q0                      // XNOR: (Q1 & Q0) | (~Q1 & ~Q0)
  - D2 = Q2 ^ (~Q1 & ~Q0)             // XOR with (~Q1 & ~Q0)
  - D3 = Q3 ^ (~Q2 & ~Q1 & ~Q0)

   [T FLIP-FLOP EQUATIONS] (T_i = Toggle Condition)
   T0 = 1
   T1 = Q0
   T2 = Q1 · Q0
   T3 = Q2 · Q1 · Q0

===================================================================================================================================
                                      SYNCHRONOUS 3-BIT BINARY COUNTER WITH ENABLE (w)
                                     D-INPUT BOOLEAN EQUATIONS & DERIVATION ANALYSIS
===================================================================================================================================

1. STATE TRANSITIONS & DERIVATION LOGIC
-----------------------------------------------------------------------------------------------------------------------------------
Let the present state be Q[2:0] = (Q2, Q1, Q0) and next state be Q+[2:0] = (D2, D1, D0).

- Bit 0 (LSB - Q0):
  * When w = 0: Retains value -> D0 = Q0
  * When w = 1: Toggles on every clock -> D0 = Q0̄
  * Boolean Expression: D0 = Q0 ⊕ w

- Bit 1 (Q1):
  * When w = 0: Retains value -> D1 = Q1
  * When w = 1: Toggles only when Q0 = 1 -> D1 = Q1 ⊕ Q0
  * Boolean Expression: D1 = Q1 ⊕ (w · Q0)

- Bit 2 (MSB - Q2):
  * When w = 0: Retains value -> D2 = Q2
  * When w = 1: Toggles only when Q1 = 1 AND Q0 = 1 -> D2 = Q2 ⊕ (Q1 · Q0)
  * Boolean Expression: D2 = Q2 ⊕ (w · Q1 · Q0)


2. COMPACT COMMENT-BOX EQUATIONS
-----------------------------------------------------------------------------------------------------------------------------------
   Notation:  ⊕ = XOR  |  · = AND  |  Q̄ = Complemented Output

   D0 = Q0 ⊕ w
   D1 = Q1 ⊕ (w · Q0)
   D2 = Q2 ⊕ (w · Q1 · Q0)


3. VERILOG LOGIC EQUATIONS
-----------------------------------------------------------------------------------------------------------------------------------
   D[0] = Q[0] ^ w;
   D[1] = Q[1] ^ (w & Q[0]);
   D[2] = Q[2] ^ (w & Q[1] & Q[0]);
