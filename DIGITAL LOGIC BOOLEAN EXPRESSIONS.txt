/*
===================================================================================================================================
                                                  DIGITAL LOGIC BOOLEAN EXPRESSIONS
                                     Notation:  ⊕ = XOR  |  ⊙ = XNOR  |  Ā = Complemented (NOT A)
===================================================================================================================================

1. HALF ADDER (Inputs: A, B)
-----------------------------------------------------------------------------------------------------------------------------------
   Sum   = A ⊕ B
   Cout  = A · B


2. FULL ADDER (Inputs: A, B, Cin)
-----------------------------------------------------------------------------------------------------------------------------------
   Sum   = A ⊕ B ⊕ Cin
   Cout  = (A · B) + (Cin · (A ⊕ B))
         = (A · B) + (B · Cin) + (A · Cin)


3. HALF SUBTRACTOR (Inputs: A, B)
-----------------------------------------------------------------------------------------------------------------------------------
   Diff  = A ⊕ B
   Bout  = Ā · B


4. FULL SUBTRACTOR (Inputs: A, B, Bin)
-----------------------------------------------------------------------------------------------------------------------------------
   Diff  = A ⊕ B ⊕ Bin
   Bout  = (Ā · B) + (Bin · (A ⊙ B))
         = (Ā · B) + (Ā · Bin) + (B · Bin)


5. 1-BIT COMPARATOR (Inputs: A, B)
-----------------------------------------------------------------------------------------------------------------------------------
   A_gt_B (A > B)  = A · B̅
   A_lt_B (A < B)  = Ā · B
   A_eq_B (A == B) = A ⊙ B
                   = (A · B) + (Ā · B̅)


6. 2-BIT COMPARATOR (Inputs: A[1:0], B[1:0])
-----------------------------------------------------------------------------------------------------------------------------------
   // Bit-wise Equality Flags:
   x1 = A1 ⊙ B1   // Bit 1 Equality Flag
   x0 = A0 ⊙ B0   // Bit 0 Equality Flag

   // Output Expressions:
   A_eq_B (A == B) = x1 · x0
                   = (A1 ⊙ B1) · (A0 ⊙ B0)

   A_gt_B (A > B)  = (A1 · B̅1) + (x1 · A0 · B̅0)
                   = (A1 · B̅1) + ((A1 ⊙ B1) · A0 · B̅0)

   A_lt_B (A < B)  = (Ā1 · B1) + (x1 · Ā0 · B0)
                   = (Ā1 · B1) + ((A1 ⊙ B1) · Ā0 · B0)

===================================================================================================================================
*/
